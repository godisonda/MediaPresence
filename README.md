# 🎵 Media Presence Tracker

Легковесная система для автоматической синхронизации воспроизведения из **Яндекс Музыки** и **YouTube** в статус активности **Discord Rich Presence (RPC)** с поддержкой глобальных хоткеев управления.

## ✨ Возможности

- **Поддержка стримингов:** Полноценная интеграция с браузерными версиями Яндекс Музыки (включая интерфейс «Моя волна») и YouTube.
- **Отображение в Discord:** Выводит обложку трека/видео, название, исполнителя/канал, статус паузы и точный таймер прогресса.
- **Глобальные хоткеи:** Управление воспроизведением без переключения в браузер (пауза/плей, следующий/предыдущий трек).
- **Автономность:** Десктопное приложение работает в фоне, поддерживает тёмную/светлую тему и автозапуск с Windows.
- **Локальная безопасность:** Обмен данными между расширением и приложением происходит строго по локальному адресу `127.0.0.1:6412` с авторизацией по PIN-коду. Никакие данные во внешнюю сеть не передаются.

## ⌨ Горячие клавиши (по умолчанию)

| Комбинация | Действие |
| :--- | :--- |
| `Alt + K` | Пауза / Воспроизведение |
| `Alt + L` | Следующий трек |
| `Alt + J` | Предыдущий трек |

*Хоткеи можно изменить на любые удобные в меню настроек десктопного приложения.*

## 🚀 Установка и настройка

### 1. Браузерное расширение
1. Перейдите в раздел [Releases](https://github.com/) и скачайте архив `media-presence-extension.zip`.
2. Распакуйте архив в любую удобную папку на компьютере.
3. Откройте страницу расширений в браузере:
   - В Chrome / Brave: `chrome://extensions/`
   - В Яндекс Браузере: `browser://extensions/`
   - В Edge: `edge://extensions/`
4. Включите тумблер **«Режим разработчика»** в правом верхнем углу.
5. Нажмите кнопку **«Загрузить распакованное расширение»** и укажите распакованную папку.

### 2. Десктопное приложение
1. Скачайте `MediaPresence.exe` из раздела [Releases](https://github.com/).
2. Убедитесь, что запущен клиент **Discord**.
3. Запустите `MediaPresence.exe`.
4. В правом верхнем углу приложения скопируйте сгенерированный **PIN**.
5. Нажмите на значок расширения в браузере, вставьте PIN в поле ввода и нажмите кнопку **«Сохранить»**.
6. Включите любой трек или видео — статус появится в вашем профиле Discord.
